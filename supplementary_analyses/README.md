# Supplementary analyses

Aggregate results and scripts supporting the paper's requested robustness and
exploratory analyses.

## Contents

- `convergence/`: how many tappers a stem's consensus needs before it stops
  changing (paper &sect;2.3), plus a final-grid disjoint-split reliability
  check. Generated by `run_globaltap_convergence_validated.py` (convergence
  curves) and `run_final_grid_reliability.py` (reliability check).
- `beat_metrics/`: madmom and Beat This! agreement with the tapping-derived
  GlobalTap consensus using beat metrics beyond F-measure (paper &sect;3.4).
  Generated by `run_globaltap_beat_metrics.py`.
- `cross_cultural/`: the one exploratory country-panel result the paper
  reports (paper &sect;3.5) -- metrical-choice and phase differences across
  the ten GlobalTap recruitment panels. See `cross_cultural/README.md`.
- `istc_cv_tracker_correlations/`: pooled ISTC/CV-vs-tracker-agreement
  correlations (paper &sect;3.4), computed on the complete 746-participant
  benchmark release. Generated by
  `run_pooled_istc_cv_tracker_correlations.py` (see its module docstring for
  provenance).
- `metrical_preference/`: complete 180-excerpt audit of Crowd-minus-Reference
  ratings by metrical relation (paper &sect;3.6). Generated by
  `reproduce_summary.py`.
- `parameter_sensitivity/`: bounded final-grid checks around active optimizer
  settings (see `METHOD_PARAMETERS.md`). Generated by
  `run_optimizer_sensitivity.py`.
- `METHOD_PARAMETERS.md`: fixed pipeline settings with a concise rationale for
  each.
